# PotencIA — Da experiência à evidência

A **PotencIA** é uma plataforma voltada a jovens em início de carreira. A solução utiliza inteligência artificial de forma responsável para ajudar o usuário a reconhecer competências desenvolvidas em experiências reais, criar evidências práticas e se preparar para entrevistas.

## Problema

Muitos jovens deixam de se candidatar a vagas por acreditarem que não possuem experiência suficiente. Na pesquisa inicial do projeto:

- 22 pessoas responderam ao formulário;
- 20 respostas de jovens entre 18 e 24 anos foram analisadas;
- 75% já deixaram de se candidatar a uma oportunidade;
- 90% utilizariam a PotencIA;
- 90% afirmaram que evidências práticas aumentariam sua confiança.

## Jornada do protótipo

1. Relato de uma experiência verdadeira.
2. Perguntas para compreender o contexto.
3. Sugestão explicável de competências.
4. Validação das competências pelo usuário.
5. Desafio prático e geração de evidência.
6. Orientação personalizada para entrevistas.

## Princípios

- A IA sugere; o jovem decide.
- Nenhuma experiência ou qualificação é inventada.
- O usuário pode corrigir ou rejeitar resultados.
- Privacidade, transparência e inclusão fazem parte do produto.
- A ferramenta apoia, mas não substitui orientação profissional.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

Baixe o repositório e abra o arquivo `index.html` no navegador. O protótipo atual não exige instalação nem servidor.

## Segurança dos dados

Este repositório não contém respostas individuais, nomes, e-mails ou outros dados pessoais da pesquisa. Apenas resultados agregados podem ser utilizados na documentação.
